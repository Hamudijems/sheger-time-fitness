# PowerFit Gym Website

A modern, responsive website for a fictional gym called PowerFit, showcasing their services, trainers, pricing plans, and more.

## Features

- Fully responsive design for all device sizes
- Modern UI with smooth animations and transitions
- Single-page layout with smooth scrolling navigation
- Interactive elements like testimonial slider
- Contact form with validation
- Accessibility improvements for keyboard navigation

## File Structure

- `index.html` - Main HTML file containing all content sections
- `styles.css` - Primary stylesheet with all core styles
- `enhanced-visuals.css` - Additional visual enhancements and effects
- `fixes.css` - Responsive fixes and form validation styles
- `animation-effects.js` - Advanced animation system for the website
- `fixes.js` - Core JavaScript functionality including navigation and form handling
- `script.js` - Additional JavaScript functionality
- `about-effects.js` - Special effects for the About section

## Sections

1. **Header/Navigation** - Sticky navigation with mobile responsive menu
2. **Hero** - Main introductory section with call-to-action buttons
3. **About** - Information about the gym with statistics and timeline
4. **Services** - Cards displaying the various services offered
5. **Trainers** - Profiles of the gym's professional trainers
6. **Pricing** - Membership plans and pricing options
7. **Testimonials** - Customer reviews with automated slider
8. **Gallery** - Image gallery of the gym facilities
9. **Contact** - Contact form and information
10. **Footer** - Site map, social links, and legal information

## Technologies Used

- HTML5
- CSS3 (with custom properties, flexbox, grid)
- JavaScript (ES6+)
- Font Awesome icons
- Google Fonts (Montserrat)
- Anime.js library for advanced animations

## Browser Compatibility

The website is compatible with:
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers

## Setup

1. Clone the repository
2. Open `index.html` in your browser

No build process or dependencies required to run the website.
